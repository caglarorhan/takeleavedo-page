1. Overview & The Three Pillars Standard User

Every stop in TakeLeaveDo is organized around three clear, actionable buckets:

1. TAKE (Pick Up) PICKUP_BRING

Items you must pick up or take with you from this stop (e.g. Laptop, Packages, Keys). Checking an item here moves it into your In-Transit Carrying inventory.

2. LEAVE (Drop Off) DROP_OFF_LEAVE

Items you must leave, deliver, or hand off at this stop. Items previously picked up at earlier stops can be selected and marked delivered here.

3. DO (Actions) DO_HERE

Tasks or custom actions you must perform at the location (e.g. Scan receipt, Collect signature, Pay bill).

Stop Status Lifecycle

StatusBadgeWhen It Happens
PLANNEDPlannedStop is scheduled for a future time window today.
CURRENTCurrentYou are physically inside the geofence (or active window). Only one stop can be CURRENT at a time.
COMPLETEDDoneYou visited the stop and completed all Take, Leave, and Do checklist items.
PARTIALPartialYou visited the stop and completed some items before departing.
MISSEDMissedThe planned time window ended without an on-site visit.

2. Flow View & Interactive Map View Standard User

Switch between Timeline and Map mode using the segmented toggle in the top bar:

  • Flow Timeline: Displays all stops for today in chronological order with arrival times, expected durations, and live status badges. Directly check items off cards as you complete them.
  • Interactive Vector Map: Visualizes your daily route with pins color-coded by stop status. Displays your real-time GPS position with a live pulsing YOU radar badge.
  • Multi-Visit Same-Place Grouping: When multiple stops occur at the same physical place throughout the day (e.g. Stop #1 morning depot pickup and Stop #5 afternoon return), the map merges them into a single non-overlapping marker box with multi-badge indicators (1 5).

3. Adding Stops & Time-Window Conflict Validation Standard User

When you tap + Add Stop, TakeLeaveDo automatically calculates a realistic arrival time defaulting to 15 minutes after the previous stop's departure.

Three-Tier Time Conflict Protection

Conflict LevelConditionApp Behavior
EXACT_MATCH Hard Block Exact identical start and end time window as an existing stop (e.g. both 10:00 - 10:30). Prevents saving. Requires selecting an alternate time window to avoid scheduling impossibilities.
PARTIAL_OVERLAP Warning Stop's window overlaps another stop (e.g. Stop 1 is 10:00 - 10:30, Stop 2 is 10:15 - 10:45). Displays a conflict warning modal highlighting the overlapping minutes before allowing you to adjust or confirm.
INSUFFICIENT_BUFFER Notice Gap between departure and next arrival is under 15 minutes. Warns you that transit buffer may be tight.

4. Slide-to-Delete with 2-Second Grace Period & Undo Standard User

Following modern mobile ergonomics, you can quickly remove any item or action from a stop with a simple swipe gesture:

  • Swipe Left: Slide the item card to the left to reveal the red Delete background.
  • 2-Second Grace Period: Upon releasing, the card transitions into an inline pending-deletion row displaying a countdown timer and a depleting progress bar ("Removing in 2s...").
  • Instant Undo: Tap UNDO to immediately cancel deletion and restore the card without modifying the database.
  • Commit: If 2 seconds elapse without tapping Undo, the item is deleted from the Room database, and stop completion statuses update automatically.

5. Checklists & Cross-Stop Item Handoffs Standard User

Tap Manage Checklist on any stop to open the full checklist editor. The app tracks inventory items across stops:

  • Pick Up (Take): Items checked here transition to PICKED_UP_IN_TRANSIT.
  • Drop Off (Leave): Displays a dedicated "Items Picked Up at Earlier Stops" selector. Tapping an in-transit item automatically pairs it to this stop for drop-off verification.

7. Hands-Free Voice Commands (Google FunctionGemma) Standard User

Activate voice capture by tapping the microphone icon or saying "Hey TakeLeave" while the screen is awake. Powered by on-device Google FunctionGemma 270M (LiteRT-LM).

Our unpunctuated voice engine parses compound requests into scheduled stops and item lists automatically.

Example Utterances:
• "Create a stop at Harbor Freight on next Monday at 3 pm, collect drill set, deliver return invoice, and ask for manager"
• "Add stop Sunrise Cafe tomorrow at 10 am for 30 minutes, pick up menu boxes, and do pay invoice"
• "What is my next stop?"
• "Mark drill set done"

8. Daily Reports & Operational Analytics Standard User

Review comprehensive statistics and route performance for any day:

  • Progress & Completion: Instant visibility into % tasks done, completed stops, and missed appointments.
  • Transit Metrics: Tracks actual time spent on-site (avg minutes/stop) and total route driving distance in miles/km.
  • Item Auditing: Separate breakdown for Pick Up (Take) and Drop-Off (Leave) handoffs.
  • History Tab: Revisit past days to audit arrival logs or copy successful past routines to today with one tap.

9. Dual GPS + Wi-Fi Fingerprinting Corroboration Power User

GPS signals can drift in underground garages or high-rise urban canyons. TakeLeaveDo solves this with hardware-backed Wi-Fi presence corroboration:

  • Hardware Keystore AES-GCM Encryption: Wi-Fi BSSID access point fingerprints are encrypted on-device.
  • Arrival Corroboration: Detecting a saved place's Wi-Fi network triggers arrival immediately even if GPS accuracy is degraded.
  • Indoor Hold: As long as your phone is connected to the place's Wi-Fi beacon, the app suppresses false GPS exit triggers.

10. Web / API JSON Import & QR Provisioning Power User / API

Fleet managers and automated dispatch servers can provision routes with zero typing:

  1. Open Settings → Enable Web / API JSON Import.
  2. Tap the QR Code icon to scan an endpoint URL (e.g. https://api.yourfleet.com/v1/flow?driver=42).
  3. On app launch or manual refresh, the app issues an HTTPS GET request with ?date=YYYY-MM-DD.
  4. Stops and places are atomically populated with duplicate suppression.

12. Full Local Backup / Restore JSON Data Backup

TakeLeaveDo provides offline database export/import under Backup & Restore. The backup JSON includes:

  • version: Schema version integer (e.g. 6)
  • exportedAt: ISO-8601 UTC timestamp
  • places[], flows[], stops[], entries[], wifiFingerprints[]

13. Database Entities (Room SQLite Schema v6) Architecture

Core local database tables:

  • places: Saved geofence locations (lat, lng, radius, street address).
  • daily_flows: Flow container for a specific date (YYYY-MM-DD).
  • flow_stops: Stops within a flow (references placeId, planned arrival, actual arrival, status).
  • flow_entries: Individual items (type: PICKUP_BRING, DROP_OFF_LEAVE, DO_HERE).
  • place_wifi_fingerprints: Encrypted Wi-Fi BSSID records.
